# Veqic 0.1 — النسخة التجريبية الداخلية (Model Card Draft)

## الهوية
- **الاسم**: Veqic 0.1 (نسخة تجريبية داخلية — لا إطلاق للجمهور)
- **الأساس**: Gemma 4 E4B (Apache 2.0) — قد يُستبدل بـ Granite 4.2 8B بعد القياسات الأولى.
- **الترخيص**: Apache 2.0 (موروث من الأساس + بياناتنا).
- **الشخصية**: مباشرة، صادقة، بدون مجاملات. يقول "لا أعرف" بوضوح. يحترم المستخدم كشريك فكري، لا كعميل. يدافع عن الشفافية وحقوق الإنسان أمام الأتمتة.

## عناصر التدريب
1. **SFT (ضبط فوقي خاضع للإشراف)** على بيانات Veqic الخاصة:
   - حوارات تُظهر الشخصية والفلسفة (الهدف: ≥ 3000 مثال).
   - أمثلة رفض صريح: عندما تطلب النتيجة تضليلًا أو مراقبة سرية أو استبدال عامل بشري ظالمًا.
   - أمثلة "لا أعرف" موثقة.
2. **DPO (تفضيلات)**: مقارنات (مثال مرغوب مقابل غير مرغوب) — الهدف ≥ 1000 زوج.

## قياسات الإصدار (إلزامية قبل النشر)
- تقييم على 200 سؤال صُمم داخليًا يقيس: الصدق، الرفض الصحيح، أسلوب الرد، الاتساق مع الفلسفة.
- تقرير علني: النتائج + نقاط الضعف + ما لم ينجح.

## خطة الإطلاق (0.1 = داخلية فقط)
1. GitHub: مستودع `veqic` — البيانات، السكربتات، الوثائق.
2. Hugging Face: أوزان النموذج + Model Card الكامل (private حتى اجتياز بوابة الجودة).
3. **واجهة Beta على HF Spaces (Gradio)**: مخصصة للمختبرين فقط — ليست منتجًا تجاريًا.
4. **طبقة الإيجننت (V2 من الواجهة)**: إطار عمل وكلاء يربط النموذج بأدوات خارجية عبر MCP (Model Context Protocol) — بحث ويب، ملفات، أدوات مخصصة. تبني فوق النموذج نفسه، وتختبر داخل الـ Beta نفسها.

## بوابة الترقية 0.1 → 1.0 (إلزامية قبل أي إطلاق تجاري)
- ArabicMMLU ≥ 55% على النسخة المضبوطة (مقابل 24% للأساس).
- تقييم بشري: 30 حوارًا عربيًا حقيقيًا، يُفضَّل Veqic على الأساس في ≥ 60% منها.
- قائمة تقييم الرفض و"لا أعرف": 20/20 حالة صحيحة.
- لو فشلت البوابة: دورة بيانات جديدة، لا إطلاق.
